# Фьюжн — концепт редизайна сайта доставки

> **Концепт для портфолио.** Редизайн выполнен по собственной инициативе и не является официальным сайтом кафе «Фьюжн». Заказы через этот сайт не принимаются и не оплачиваются. Телефоны и домен вымышленные, страницы закрыты от поисковиков.

Кафе японской кухни «Фьюжн» работает в Балакове и Вольске с 2009 года. Задача концепта — сделать заказ доставки быстрым и понятным с телефона. Нужно было сократить путь от меню до оплаты, показать зону и время доставки до оформления и дать клиенту контроль над этапами заказа.

## Что внутри

- **Главная**: хиты, акции, статус работы кафе.
- **Меню**: 208 карточек. Похожие блюда объединены в одну карточку с выбором варианта (начинка, соус, подача), меню стало на 38 позиций короче.
- **Страница блюда**: состав, КБЖУ, «С этим берут».
- **Корзина и оформление**: доставка или самовывоз, «как можно скорее» или ко времени. Оформление — демо: после него открывается пример страницы статуса заказа.
- **Профиль**: история и повтор заказа.
- **Дизайн-система**: цвета, типографика, компоненты, состояния (`design-system.html`).

Сайт статический: HTML, CSS и чистый JavaScript, без сборки. Данные меню лежат в `data/menu.json`.

## Фото блюд

Исходные фото взяты со старого сайта и приведены к одному виду: белый фон, кадр 4:3, одинаковые поля. Наклонённые блюда выровнены по горизонтали, а там, где блюдо обрезано краем исходного кадра, срез совмещён с краем карточки. Фото используются только для демонстрации концепта.
